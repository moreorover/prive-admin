# Alchemy v2 Only Cloudflare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Terraform split in PR #284 with an Alchemy-only Cloudflare deployment model for dev, prod, and PR previews, while migrating the Alchemy stack to v2.

**Architecture:** Alchemy owns D1, R2, server Worker, web Worker, and preview comments from one TypeScript stack. Stable stage resources keep explicit physical names and adoption enabled; preview stages remain deletable. Terraform files and workflows are removed so there is one Cloudflare IaC owner.

**Tech Stack:** Vite+, pnpm workspace, GitHub Actions, Cloudflare Workers, Cloudflare D1, Cloudflare R2, Alchemy 2 beta, Effect.

## Global Constraints

- Run `vp install` after dependency changes.
- Run `vp check` and `vp test` to format, lint, type check and test changes.
- Check if there are `vite.config.ts` tasks or `package.json` scripts necessary for validation, run via `vp run <script>`.
- Keep existing untracked files untouched.
- Do not commit Cloudflare account IDs, API tokens, Better Auth secrets, or production URLs.
- Keep stable Cloudflare resource names pinned to the existing dev/prod names.
